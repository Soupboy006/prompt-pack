# Study Prompts - Learn From Zero

## Explain like I'm 12
```
Explain [topic] to me like I'm 12.
No jargon. Use a daily life example.
At the end ask me 3 short quiz questions.
```

## Make a 7-day plan
```
I want to learn [topic] from zero.
I have [30 minutes] per day.
Make a 7-day plan with 1 tiny task per day.
```

## Check my understanding
```
I think [topic] means: [your explanation].
Correct me in simple words and give 1 example.
```
