# Phone Help Prompts

## Fix Android problem step by step
```
My phone is [model]. Problem: [describe what happens].
I am a beginner, using Termux / Android.
Give me step-by-step fix. Ask me 1 question at a time if you need info.
```

## Understand an error
```
I got this error:
[paste error]
Explain in simple words what happened and give 2 safe things to try first.
```

## Ask for Termux command safely
```
I want to [goal] in Termux.
Give me the exact commands, explain each line, and warn me before anything risky.
```

## Phone feels slow
```
My phone is [model / Android version] and it feels slow.
I am a beginner. Give me 5 safe things to try, easiest first.
Do NOT ask me to factory reset or delete my photos.
```

## Storage full — what can go safely
```
My phone says storage is full. Model: [x].
Explain what safely deletes: cache, downloads, app data.
Tell me what to keep (photos, WhatsApp data, contacts).
Give the exact taps for my phone version.
```

## Battery drains fast
```
My [model] battery goes from 100% to empty in [hours].
List what checks first: [battery menu, apps, screen brightness].
Ask me 1 question at a time and give the fix plus how to check it worked.
```

## App will not install or update
```
The app [name] will not [install / update] on my [model].
Error says: [paste error].
Give beginner-safe steps, then the risky ones only if the safe ones fail.
```

## Recover a deleted photo
```
I deleted a photo/video on my [model] on/around [date].
Is it in trash, Google Photos, or a backup?
Tell me where to check in order, and stop me before I overwrite it.
```

## Turn off annoying notifications
```
I keep getting [type of notifications] on my [model].
Show me how to stop them but keep the ones that matter ([messages, banking]).
Exact taps, beginner language.
```

## Set up phone backup
```
Set up automatic backup for my [model].
What: [photos / contacts / messages / files].
Ask what I want to keep, then give steps and how to test the backup actually works.
```

## Before installing an app
```
I want to install [app name / link].
Check: is it official, what permissions does it need, red flags?
Give me a go/no-go and tell me what settings to turn on after install.
```

## Make an unknown number stop
```
I get calls/messages from [number]. It says [what it says].
Tell me how to block the number, report it, and whether I should reply.
```

## One unknown app permission is scary
```
The app [name] is asking for permission to [camera / contacts / files].
Explain what it can really do with this permission.
Should I allow, allow once, or refuse? Plain words.
```

## Termux: before a risky command
```
Review this command before I run it in Termux: [paste command]
What will it change? Can it delete or break anything?
How do I back up first, and how do I undo it?
```

## Termux: update everything safely
```
How do I update all my Termux packages safely?
Include: the update command, what each part means, and what to do if mid-way it fails.
```
