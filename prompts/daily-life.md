# Daily Life Prompts

## Write a polite message
```
Write a short polite message to [person] about [topic].
Context: [1-2 lines].
Tone: friendly and simple.
```

## Plan my day
```
I have these tasks: [list].
I have [X hours] free.
Make a simple step-by-step plan with breaks.
```

## Explain a form or bill
```
Explain this in simple words for a beginner:
[paste text or photo description]
Tell me: what it means, what I need to do, what to ignore.
```

## Translate + make natural
```
Translate this to [language]:
[text]
Make it sound natural, not robotic. Give 2 versions: formal and casual.
```

## Say no politely
```
Someone asked me to [request] and I do not want to do it.
Write a kind short reply that says no without hurting them.
Person: [friend / family / boss].
```

## Ask for a refund
```
I bought [item] from [shop] on [date]. Problem: [what is wrong].
I paid [amount]. Write a short firm message asking for a [refund / replacement].
Keep it polite but do not give up.
```

## Complaint that gets an answer
```
Write a short complaint about [problem] to [company].
Facts: date [x], amount [x], what happened [x], what I already tried [x].
End with exactly what I want them to do.
```

## Invitation message
```
Write a short invite for [event] on [date/time] at [place].
Party size: [x]. Tone: [fun / respectful].
Give 2 versions: long message and one-line version for WhatsApp.
```

## Birthday or festival wish
```
Write a birthday wish for [relationship: mother / friend / boss].
Their age [x]. Reach: [memories or inside jokes].
Give 3 versions: heartfelt, funny, short.
```

## Reschedule politely
```
I have an appointment / meeting on [date/time] with [person].
I need to change it to [new time].
Write a short message that apologizes once and offers the new time.
```

## Prepare for a doctor visit
```
I have these symptoms: [list]. Since [how long].
Give me 5 clear questions I should ask the doctor,
and 5 things to tell them so they get the full picture.
```

## Split a cost fairly
```
[x] people shared [thing] and paid: [who paid what].
Total cost: [amount].
Show who owes whom the smallest number of payments.
Explain it simply.
```

## Is this message a scam?
```
I received this message/call: [paste it].
Is it likely a scam? Check for: urgency, payment demands, links, fake authority.
Tell me the risk level and what a safe next step is.
```

## Weigh a decision
```
I need to decide between [option A] and [option B].
My situation: [1-2 lines]. I care most about [money / time / safety].
List the pros and cons of each, then tell me what you would choose and why.
```
