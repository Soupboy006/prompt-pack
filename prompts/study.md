# Study Prompts - Learn From Zero

## Explain like I'm 12
```
Explain [topic] to me like I'm 12.
No jargon. Use a daily life example.
At the end ask me 3 short quiz questions.
```

## Make a 7-day plan
```
I want to learn [topic] from zero.
I have [30 minutes] per day.
Make a 7-day plan with 1 tiny task per day.
```

## Check my understanding
```
I think [topic] means: [your explanation].
Correct me in simple words and give 1 example.
```

## Focus session for hard study
```
I have [time] today and [task] is hard for me.
Break it into [4 x] small focus chunks with real breaks.
Tell me what to do in each chunk and what "done" looks like.
```

## Remember a long chapter
```
Here are my notes: [paste them].
Turn them into: 10 short questions, mnemonics, and a 1-minute recall summary.
Then quiz me on 5 of them.
```

## Make flashcards from my notes
```
Turn my notes into flashcards.
Front: 1 question, max 15 words. Back: 1 short answer.
Notes: [paste]. Give 15 cards, keep language simple.
```

## Explain a hard sentence
```
This sentence confuses me: [paste sentence].
Break it into pieces and explain each work in 5 lines.
Then say the idea in one simple sentence.
```

## Explain a math problem step by step
```
Explain how to solve this: [paste the problem].
Number every step and say WHY each step happens.
Give me one similar problem to try on my own (but wait for my answer).
```

## Is this source trustworthy?
```
I am researching [topic]. Here are 2 sources: [link A], [link B].
Who wrote each, how recent, any reasons not to trust it?
Tell me the one to use for facts and what to double-check.
```

## Outline an essay the easy way
```
I must write an essay on [topic], about [length in words].
Make an outline: hook, 3 main points each with evidence I should hunt for, conclusion.
Mark which parts I should research myself.
```

## English speaking practice
```
Practice speaking with me about [topic].
You ask 1 question, wait for my answer, then correct my grammar in max 3 tips.
Keep it friendly. Go level: [beginner / medium].
```

## Practice from a video
```
Here are notes/transcript from a video I watched: [paste].
Teach it back 3 difficulty levels: super simple, normal, deeper.
Then check with 5 questions what I actually learned.
```

## Exam week revision plan
```
My exam is in [x days], date [date], subjects: [list].
Weak areas: [list]. Daily time: [hours].
Make a count-down plan: revise, practice, sleep, light day before, exam morning plan.
```

## Ask better questions
```
I am stuck on [topic] at this point: [where you get lost]?
Rewrite my confusion as 3 sharp questions to ask my teacher / ask AI next,
ordered from most basic to most advanced.
```
