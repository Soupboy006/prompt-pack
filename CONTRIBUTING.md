# Contributing - super simple

You don't need to know git.

Option 1 - Easiest (recommended):
1. Go to Issues in this repo
2. Click `Add a prompt`
3. Write your prompt in plain words
4. Submit. That's it.

Option 2 - Edit file:
1. Fork this repo
2. Edit a file in `prompts/`
3. Open a Pull Request

Rules:
- Keep language simple
- One prompt = one task
- Use [brackets] for parts to replace
- No personal data
