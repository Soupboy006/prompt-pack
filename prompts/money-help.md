# Money Help Prompts

## Explain a bank message or SMS
```
I got this money message: [paste SMS / notification].
Explain in simple words what it means, if I must do anything, and if any part looks wrong.
Flag anything that asks me to click a link or share a code.
```

## Monthly budget from my income
```
My monthly income: [amount]. Fixed bills: [rent,
loans, family support]. Spending style: [describe].
Make a simple budget: needs, wants, save. Use the 50/30/20 idea but adapt.
Tell me the one leak that will surprise me.
```

## Wrong charge or money lost
```
I paid [amount] to [who] on [date] and got [nothing / wrong item / overcharged].
Write a short escalation message: polite first line, facts, deadline, what happens if no fix.
Add what proof I should collect today (screenshot, receipt, transaction id).
```

## Can I afford this?
```
I want to buy [thing] for [price]. My monthly income: [amount],
savings: [amount], debts: [amount].
Ask me 3 questions to understand my situation, then tell me straight if it is a yes, no, or wait.
```

## Save first, or clear a loan?
```
I have [amount] spare. I have [loan type, rate] and no emergency fund.
Compare: extra saving vs paying the loan early.
Simplicity: explain like I am 12, give one clear suggestion.
```

## Compare two loan offers
```
Loan A: [amount, rate, total to repay]. Loan B: [amount, rate, total to repay].
Show the real cost difference in money, not just rate.
Tell me in 1 line which to pick and why.
```

## Cancel a subscription
```
I want to cancel [service / plan]. I use it [how often].
Give me: how to cancel myself, the exact polite but firm cancellation message, and how to confirm I am not billed again.
```

## Choose the right phone/data plan
```
I use data mostly for [work / video / WhatsApp]. Usage estimate: [gb and calls].
Compare 3 plan types and tell me how to check my real usage first
so I do not over-pay.
```

## Savings goal plan
```
Goal: [thing] cost [amount], target [date]. I can put aside [amount] weekly.
Make a simple tracker table with weeks, contributions, and total.
Tell me what to cut if I fall 20% behind.
```

## Rule check for a deal
```
Someone offered me [deal / investment] with [returns / discount promises].
List 5 yes/no checks that separate a real deal from a scam (registered? pressure?
withdrawal proof?). Tell me the fastest way to verify each.
```

## Price my small service
```
I offer [service] locally. My time: [hours per job]. My costs: [list].
Help me set a fair price: floor price (below this I lose),
fair price, and premium price with what I should add to earn it.
```

## Weekly money habit (10 minutes)
```
Design a 10-minute weekly money check-in for a beginner.
Steps: total spend, top 3 items, one rule for next week.
Output: a tiny template I can repeat every Sunday.
```
